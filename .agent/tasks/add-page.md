# Add Angular Page

Use this checklist when adding a route-level Angular page.

## Steps

1. Add a standalone component under `frontend/src/app/features`.
2. Lazy-load the route.
3. Use typed services for API calls.
4. Prefer generated API models when available.
5. Add loading, empty, and error states.
6. Keep protected behavior enforced by the backend.
7. Run the frontend build.

## Done Means

- Page is reachable through routing.
- Data access is typed.
- Layout works at narrow and wide widths.
- Frontend build passes.
