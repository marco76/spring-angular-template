# Specifications

Put project-specific written specifications here after creating an application from the template.

Use this folder for:

- Product requirements
- Business rules
- User flows
- Technical specifications
- External integration notes
- Acceptance criteria

Recommended names:

```text
product-spec.md
technical-spec.md
auth-spec.md
reporting-spec.md
integration-<system>.md
```

Before changing behavior, APIs, database schema, UI flows, or business rules, agents should read the relevant files in this folder.

If a specification and the implementation disagree, clarify the intended contract before changing code.
